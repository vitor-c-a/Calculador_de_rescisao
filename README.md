Cálculo de Rescisão Trabalhista – CLT

Este projeto é uma aplicação web que realiza o cálculo aproximado de rescisão trabalhista para contratos regidos pela CLT. O objetivo é fornecer ao trabalhador uma estimativa rápida e acessível do valor a receber em caso de desligamento da empresa.

⚙️ Tecnologias utilizadas: HTML, CSS e JavaScript.

📌 Aviso: Os valores apresentados são apenas estimativas. Para resultados exatos e adequados ao seu caso específico, recomenda-se consultar um contador ou profissional de RH.
